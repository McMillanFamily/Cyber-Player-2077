# Cyber-Player-2077

A simple music player Built in rust 

Created as a learning project for me to learn rust 

## What it does
- It lets you select a music file (mp3, wav, flac) and play these music files

## Built with

- **Rust** all logic and file handling
- **Slint** all the UI elemnts and look of it

## How to run

```
git clone https://github.com/McMillanfamily/Cyber-Player-2077
Cd Cyber-Player-2077
cargo run
```
